海王钓鱼 —— 完整项目归档
====================================

【目录结构】

  海王钓鱼_投放版.html   一键成品(所有素材/音效/代码全内联,双击即玩,可直接投 AppLovin/微信)
  index.html             开发入口(引用外部 src 和 assets,配合 启动调试.bat 使用)
  启动调试.bat           一键起本地服务器(端口 8765),用于开发调试
  build_standalone.py    一键打包脚本:把 src/ + assets/ 内联进 index.html → 生成投放版
  compress_assets.py     素材压缩脚本:从 _assets_orig/ 重新压缩到 assets/(体积超预算时用)

  src/                   源代码
    game.js              游戏主逻辑(渔夫、鱼群、海王、擦边、音频、UI、加载界面…)
    style.css            页面样式
    debug.js             编辑器(WAVE_CFG/UI_LAYOUT/LOADING_UI 等可视化调参 + 导出 H5)
    assets_b64.js        素材 base64 缓存(build 自动生成)
    _export_src.js       html/css/js 快照(build 自动生成,供页面内导出按钮用)

  assets/                当前用于游戏的素材(已压缩到合适尺寸)
    *.png / *.jpg / *.webp
    audio/               17 个音效 mp3(音量已烘进文件)

  _assets_orig/          未压缩原始素材备份(用 compress_assets.py 时的源)


【常用操作】

  ▶ 修改代码后重新打包:
      python build_standalone.py
    → 生成 seaking_standalone.html(即"海王钓鱼_投放版.html")

  ▶ 本地调试:
      双击"启动调试.bat" → 浏览器打开 http://localhost:8765
    (编辑器 debug.js 在此模式下可用;直接双击 index.html 用 file:// 打不开跨域素材)

  ▶ 素材超出投放体积预算(4.5MB):
      python compress_assets.py    # 从 _assets_orig 重新压
      python build_standalone.py   # 再打一次包


【投放要求】

  · AppLovin/Facebook 等平台上限 5MB → 保持"海王钓鱼_投放版.html" ≤ 4.5MB
  · build 脚本会在超预算时报警并列出最大的几张图
